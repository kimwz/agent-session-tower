# Agent Session Tower

[English](README.md)

**Claude Code와 Codex의 harness를 그대로 쓰면서, 웹 UI에서 여러 세션과 에이전트를 한눈에 관제하고 관리하세요.**

여러 세션에서 여러 에이전트를 동시에 돌리거나 리모트로 관리할 때 특히 유용합니다.

명령어 하나로 기존 로컬 세션을 프로젝트별 그래프에 모아 볼 수 있습니다.

```sh
npx --yes github:kimwz/agent-session-tower
```

리포지토리를 직접 clone해서 실행할 수도 있습니다.

```sh
git clone https://github.com/kimwz/agent-session-tower.git
cd agent-session-tower
npm ci
npm start
```

`npm ci`가 의존성 설치와 앱 빌드를 자동으로 처리합니다.

브라우저에서 **http://localhost:8000**이 열리고, 아래와 같은 노드형 캔버스로 바로 관제할 수 있습니다.

![Claude Code와 Codex 세션을 프로젝트별 노드로 보여주는 Agent Session Tower 그래프 캔버스](docs/images/session-graph.png)

**Node.js 22.13 이상**, **npm**, **Git**이 필요합니다. 설치하고 로그인해 둔 Claude Code 또는 Codex를 사용합니다. 처음 실행할 때 앱을 내려받아 빌드하며, 이후에는 npm 캐시를 활용합니다. macOS에서 검증했으며, 웹 UI는 **한국어와 영어**를 지원합니다.

## 브라우저 에디터와 터미널

프로젝트 폴더나 세션의 에디터·터미널 아이콘을 누르면 오른쪽 오버레이로 해당 작업 공간이 열립니다. 채팅창이 열려 있으면 겹치지 않도록 채팅창 왼쪽에 배치됩니다. 오버레이 왼쪽 경계를 드래그해 너비를 조절할 수 있습니다(최소 420px, 화면이 더 작으면 화면 너비). 작업 공간과 채팅창은 각각 사용자가 조절한 너비를 이 브라우저에 저장합니다. 좁은 화면에서는 작업 공간과 채팅창을 위아래로 배치합니다. 파일 탐색기에서 파일을 열고, 새 파일·폴더를 만들고, Ctrl/Cmd+S로 저장할 수 있습니다. 저장하지 않은 변경사항은 파일 전환이나 페이지 이동 전에 확인하며, 외부에서 변경된 파일은 덮어쓰지 않고 충돌을 알립니다. 충돌 시 변경 내용을 확인하고 **파일 다시 불러오기**로 최신 파일을 불러올 수 있습니다.

내장 터미널은 Tower 서버의 해당 폴더에서 대화형 셸을 실행합니다. 원격 접속에서도 데스크톱 앱 없이 사용할 수 있습니다. 터미널 아이콘을 누르면 터미널만 표시됩니다. **터미널 최대화 해제**로 에디터·파일 탐색기를 함께 표시하고, **터미널 최대화**로 다시 터미널만 볼 수 있습니다. 터미널 패널을 숨겨도 셸은 유지되며, **터미널 종료**로 종료할 수 있습니다. 파일 편집과 명령 실행은 서버의 실제 작업 공간에 반영됩니다.

## 지원하는 기능

- **기존 세션 자동 발견** — 터미널이나 앱에서 시작한 Claude Code·Codex의 로컬 세션 기록을 자동으로 모아 보여줍니다.
- **실시간 그래프 관제** — 프로젝트, 세션, 서브에이전트를 함께 보고 작업 중·입력 대기·완료·오류 상태를 확인합니다. `/tmp`와 `/private/tmp` 아래 임시 프로젝트는 캔버스에서 제외하며, 해당 세션은 사이드바에서 계속 열 수 있습니다.
- **계정 사용량 확인** — 머신 노드 안의 도넛으로 Claude Code·Codex 사용량을 확인합니다. 마우스를 올리거나 선택하면 기간별 사용률과 초기화 시각을 보여줍니다.
- **새로운 세션 생성** — 웹에서 Claude Code 또는 Codex와 작업 폴더를 선택하고 첫 요청을 보냅니다. 없는 폴더는 자동으로 만들고, 해당 CLI의 폴더 신뢰 확인도 자동으로 처리합니다.
- **프롬프트 자동 전달** — 컴퓨터나 폴더의 반짝이 버튼으로 **Auto Prompt**를 엽니다. 별도의 Opus 또는 GPT Sol 에이전트가 적절한 기존 세션을 선택하거나 새 세션을 만들고, 선택 이유를 보여줍니다.
- **빠른 추천과 조용한 알림(선택)** — 헤더의 **빠른 판단**에 Jev API 키를 저장하면, Auto Prompt를 쓰는 동안 프로젝트와 세션을 추천합니다. 체크박스를 켠 채 보내면 그곳에서 바로 시작합니다. 알림은 중간 단계였던 턴을 건너뜁니다.
- **같은 대화에서 작업 계속하기** — 원본 대화를 읽고 같은 네이티브 세션에 다음 지시를 보냅니다. 파일 첨부와 이미지 붙여넣기도 지원합니다.
- **진행 중인 작업에 요청 끼워넣기** — 대기 중인 요청의 **지금 끼워넣기**를 누르면 작업을 중지하지 않고 같은 Claude Code·Codex 세션에 전달합니다. Tower가 제어하는 실행에서 지원하며, 다른 모델을 지정한 요청은 다음 차례를 기다립니다. 전달 여부가 불확실한 요청은 자동 재전송하지 않습니다.
- **모델과 추론 수준 선택** — 에이전트 기본값을 그대로 사용하거나, 다음 요청·새 세션·Auto Prompt에 사용할 모델과 추론 수준을 선택합니다.
- **채팅에서 실행 승인과 질문 응답** — Tower에서 직접 시작하거나 에이전트가 Tower로 넘긴 모든 턴은 에이전트의 자동 승인 방식(Claude Code의 auto 모드, Codex의 자동 검토)으로 실행됩니다. 자동 승인을 쓸 수 없을 때를 포함해 여전히 확인이 필요한 요청은 웹에서 처리합니다. 대상은 Codex와 하위 에이전트의 작업 승인, 질문 응답, 지원되는 커넥터 입력 폼입니다. 기존 Codex 데스크톱 세션의 승인은 원래 앱에서 처리합니다.
- **프로젝트 소속 유지** — 에이전트가 작업 중 다른 폴더로 이동해도 세션은 시작 폴더에 유지됩니다. Tower에서 재개할 때도 해당 프로젝트 폴더를 사용합니다.
- **브랜치 동기화** — git 프로젝트 폴더에 브랜치가 원격보다 몇 커밋 뒤처졌는지(↓), 푸시하지 않은 커밋이 몇 개인지(↑) 표시합니다. Tower가 백그라운드에서 fetch하고, 폴더에서 작업을 시작하기 전에 뒤처지기만 했고 커밋하지 않은 변경과 작업 중인 에이전트가 없으면 fast-forward합니다. 그 밖의 경우는 배지를 열어 직접 받거나 푸시합니다(강제 푸시 없음).
- **모든 에이전트에 같은 기본 지침** — Tower가 시작할 때 전역 `~/.claude/CLAUDE.md`(`~/.agent-monitor/agent-guidance.md` import)와 `~/.codex/AGENTS.md`에 짧은 섹션을 넣습니다. 저장소를 바꾸기 전에 fetch와 fast-forward를 하고, 다른 에이전트와 폴더를 같이 쓰면 별도 worktree를 쓰며, 푸시하지 않은 커밋은 반드시 알리라는 내용입니다. 파일의 나머지 내용은 그대로 둡니다. 특정 파일에서 빼려면 `<!-- agent-session-tower:off -->`를 적어 두세요.
- **내 방식으로 정리** — 세션·프로젝트 이름 변경, 프로젝트 고정, 노드 드래그, 검색·필터, 세션 숨기기·다시 열기를 지원합니다.
- **새 활동 확인** — 아직 읽지 않은 응답과 작업 결과를 표시합니다.
- **리모트 접근** — 같은 LAN이나 VPN의 다른 기기에서 비밀번호로 접속해 웹으로 관제합니다.
- **항상 최신 유지** — 백그라운드 서비스로 설치하면(`agent-session-tower service install`) Tower, Claude Code, Codex가 스스로 최신 버전을 유지합니다. 연결된 컴퓨터도 이 Tower를 따라 업데이트됩니다. 실행 중인 에이전트와 터미널은 중단되지 않습니다.

로컬 사용에는 Tower 로그인이 필요 없으며, 원격 사용에는 서버에서 계정을 설정해야 합니다. 별도 API 키, 데이터베이스, CLI 후크 설정은 필요하지 않습니다. Tower가 쓰는 에이전트 설정 파일은 위의 지침 섹션뿐입니다. 기존 CLI 계정과 모델 설정을 그대로 사용합니다.

## 리모트 접근

실행 중인 Tower를 `Ctrl+C`로 종료한 뒤 다음 명령으로 시작합니다.

```sh
npx --yes github:kimwz/agent-session-tower --host 0.0.0.0 --port 8000
```

서버 컴퓨터에서 `http://localhost:8000`을 열고 전체 내비게이션 우측 상단의 **계정 관리** 아이콘으로 ID와 비밀번호를 설정하세요. 다른 기기에서는 터미널에 출력된 네트워크 주소를 열어 로그인합니다. 로컬 접속에는 로그인이 필요 없습니다. 같은 IP에서 누적 5회 실패하면 영구 차단되며, 로컬 계정 관리에서 성공·실패 기록을 확인하고 차단을 해제할 수 있습니다. 비밀번호는 salt를 포함한 해시로만 저장됩니다. 에이전트가 있는 컴퓨터와 Tower는 계속 실행되어 있어야 합니다.

직접 접속은 HTTP를 사용하므로 암호화된 VPN 또는 별도로 보안을 구성한 HTTPS 환경에서 사용하세요. [리모트 접근 상세 안내](docs/usage.md#remote-access)를 참고하세요.
